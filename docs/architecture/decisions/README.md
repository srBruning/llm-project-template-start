# Registros de decisão arquitetural (ADRs)

Crie um ADR quando uma decisão for difícil de reverter, alterar contratos ou
estabelecer um padrão que futuros contribuidores precisem entender. Numere em
sequência (`0001-titulo.md`) usando `TEMPLATE.md`.

Estados: `proposto`, `aceito`, `substituído` ou `rejeitado`. Não reescreva a
história de um ADR aceito; crie outro e indique qual decisão ele substitui.

# Planos de tarefa

Use esta pasta para mudanças complexas ou que possam atravessar sessões. Copie
`TEMPLATE.md` para `AAAA-MM-DD-nome-curto.md`. Um plano deve explicar resultado,
escopo, decisões, progresso e validação o suficiente para outro agente continuar
sem depender do histórico do chat.

Não crie planos para correções triviais. Ao concluir, marque o resultado e remova
detalhes transitórios que não ajudam manutenção futura.
